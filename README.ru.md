# SteamOS TV Control

[English](README.md) · Русская инструкция

Сделайте ПК со SteamOS удобнее, как консоль: телевизор включается при запуске
или пробуждении ПК и уходит в ожидание при сне или выключении ПК.
При перезагрузке ПК телевизор остаётся включённым.

Подходит для телевизоров со встроенной Google TV или Android TV. Проверено на
TCL 65C7L. ПК и телевизор должны быть подключены к одной домашней сети.

## Перед установкой

Включите телевизор и подключите ПК к одному из его HDMI-входов.

На TCL включите **повышенное энергопотребление**, **Screenless service** или
настройку, которая оставляет телевизор доступным при выключенном экране.
Название зависит от модели. На проверенном 65C7L пробуждение по сети заработало
после включения повышенного энергопотребления.

## Установка

Перейдите в **режим рабочего стола** SteamOS, откройте **Konsole** и вставьте:

```bash
curl -fsSL https://github.com/Tipfurion/steamos-tv-control/releases/latest/download/install.sh | bash
```

Будет установлена последняя опубликованная версия. Если нужна конкретная
версия, используйте команду из её описания на [странице выпусков](https://github.com/Tipfurion/steamos-tv-control/releases).

Команда найдёт телевизор и выполнит настройку. Введите код с экрана телевизора,
затем выберите HDMI-вход, к которому подключён ПК. Если найдено несколько
телевизоров, выберите нужный из списка. Мастер настройки не запускается.

Если ПК пока не подключён к телевизору, нажмите Enter на вопросе о HDMI.
Управление питанием всё равно будет настроено. Выбор HDMI можно настроить позже.

SteamOS может запросить разрешение на автоматический запуск. После установки
вернитесь в игровой режим и пользуйтесь ПК как обычно. Разблокировать или
изменять системные файлы SteamOS не требуется.

## Дополнительные настройки

Чтобы сменить телевизор, настроить переключение HDMI или отключить
автоматический уход телевизора в ожидание, откройте настройки:

```bash
~/.local/bin/steamos-tv-control setup
```

Следуйте подсказкам на экране. Для выхода нажмите `q`.

## Обновление и удаление

Для обновления снова выполните команду установки. Настройки сохранятся.

Удалить приложение:

```bash
~/.local/bin/steamos-tv-control uninstall
```

Удалить приложение вместе с сохранёнными настройками:

```bash
~/.local/bin/steamos-tv-control uninstall --purge
```

## Если что-то не работает

Проверьте, что телевизор подключён к той же домашней сети и остаётся доступным
при выключенном экране. На TCL проверьте настройку энергопотребления, указанную
выше. Отправляйте телевизор в ожидание коротким нажатием кнопки пульта: после
полного выключения пробуждение по сети недоступно.

Посмотреть, что делает приложение:

```bash
journalctl --user -u steamos-tv-control -f
```

Для выхода из просмотра журнала нажмите Ctrl+C.
