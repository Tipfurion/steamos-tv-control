## Changes

- Fix TV standby before SteamOS disconnects Wi-Fi for sleep. The installer
  automatically installs the NetworkManager integration, requesting sudo
  authorization when necessary. The SteamOS system image remains read-only.
- Fix TCL power commands after connection startup and recover pending power
  actions when confirmation arrives late. Undelivered commands are discarded
  before they can run after resume.
- Add direct HDMI selection through Android TV input links. Setup offers this
  method on TCL when the HDMI button does not work, with visual confirmation.
- Keep the TV connection ready for sleep events and reconnect with a fresh
  power report after resume. Improve timeout handling, WOL fallback and logs.
- Make controller deadline tests independent of CI disk speed using virtual
  time. Race-enabled controller tests passed 100 repetitions on macOS and Linux.
- Fix waiting for process exit in terminal tests after the PTY closes.

Verified on SteamOS 3.8.28 and TCL 65C7L, including two real sleep/wake cycles
and automatic HDMI 2 selection. Automated tests run on macOS and Linux.

## Updating

Run the installation command below. Your TV pairing and settings are preserved.
An existing installation may request your password once to enable standby
before Wi-Fi disconnects. Existing TCL HDMI settings can be adjusted with
`steamos-tv-control setup` if the direct HDMI button does not work.
